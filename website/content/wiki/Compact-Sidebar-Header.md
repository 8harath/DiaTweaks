
Moves the pinned tabs up into the empty space under the window buttons, and puts the window buttons where Dia puts them with tabs at the top. It only changes the sidebar, so it does nothing with tabs at the top.

![Compact sidebar header off, then on](https://raw.githubusercontent.com/wiki/JaceThings/DiaTweaks/previews/vertical-compactSidebarHeader.webp)

## Why use it

The sidebar header leaves an empty band beside the window buttons. Moving the pinned tabs up into it frees room for the tab list.

- Handy if you have a short screen or lots of tabs.
- It only affects tabs in the sidebar.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Compact Sidebar Header**. Or run:

```sh
diatweaks enable compactSidebarHeader
```

## FAQ

<details>
<summary><strong>Does it change the sidebar that floats over the page?</strong></summary>

Yes, its header is trimmed too, so the pinned tabs and window buttons move up a little. The buttons only go to the top-tabs spot when they're already near the window's corner, which they aren't in the floating sidebar.

</details>
