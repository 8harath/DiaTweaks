Hides the Skills and Learn Skills buttons under the search field on new tab pages.

## Why use it

The Skills and Learn Skills buttons take up space on the new tab page. If you don't use skills, or want the page to show only the search field, this hides them.
Skills still work from elsewhere in Dia.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Hide Skills Suggestions**. Or run:

```sh
diatweaks enable hideSkillsSuggestions
```

## FAQ

<details>
<summary><strong>Can I still use skills?</strong></summary>

Yes. This only hides the buttons on new tab pages.

</details>
