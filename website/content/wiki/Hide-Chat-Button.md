## Why use it

If you don't use Chat, the button is a permanent bit of clutter at the toolbar's corner, and easy to click by accident.

- Handy if you want a quieter toolbar.
- Chat is still in the menu, so nothing is lost.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Hide Chat Button**. Or run:

```sh
diatweaks enable hideChatButton
```

## Works with

While [Hide Toolbar](Hide-Toolbar) is on, the button is hidden with the rest of the toolbar and this switch is greyed out in Settings. With [Show Toolbar on Hover](Show-Toolbar-on-Hover) too, the button stays hidden when the toolbar shows, as long as this tweak is on.

## FAQ

<details>
<summary><strong>Can I still use Chat?</strong></summary>

Yes. This only hides the button. Chat is still in Dia's **File** menu.

</details>
