Adds **Save Page As…** to the File menu, above Print, with a shortcut. It saves the page you're on, as Chrome does, which Dia only offers in the page's right-click menu.

![Save Page As](https://raw.githubusercontent.com/wiki/JaceThings/DiaTweaks/previews/vertical-savePageAs.webp)

## Why use it

Dia only offers Save Page As… in a page's right-click menu, so there's no menu item or shortcut for it. This adds one to the File menu, like Chrome.
Use it when you want to keep a copy of a page, like an article or receipt, as a file on your Mac.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Save Page As**. Or run:

```sh
diatweaks enable savePageAs
```

## Change the shortcut

It's **⌥⌘S** to begin with, because ⌘S shows and hides the sidebar. Under the switch, click **Shortcut** and press the keys you want. It needs ⌘, ⌃ or ⌥, unless it's a function key. Press Delete to clear it, or Escape to keep the one you had.
