
Hides the sidebar button at the top left of the toolbar.

## Why use it

If you open and close the sidebar with the keyboard or never close it, the button is clutter. Removing it gives the toolbar a quieter corner.

- Handy if you already use Dia's sidebar shortcut.
- Skip it if you click the button to open the sidebar.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Hide Sidebar Button**. Or run:

```sh
diatweaks enable hideSidebarButton
```

## Works with

While [Hide Toolbar](Hide-Toolbar) is on, the button is hidden with the rest of the toolbar and this switch is greyed out in Settings. With [Show Toolbar on Hover](Show-Toolbar-on-Hover) too, the button stays hidden when the toolbar shows, as long as this tweak is on.
