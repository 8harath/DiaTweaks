Lets the page show through the sidebar when it floats over it, with the sidebar hidden, instead of the theme color covering it.

![Translucent sidebar off, then on](https://raw.githubusercontent.com/wiki/JaceThings/DiaTweaks/previews/vertical-translucentSidebar.webp)

## Why use it

The floating sidebar covers part of the page with a solid color. With this it lets the page show through, which looks lighter and keeps context.

- Handy if you use the hidden, floating sidebar and like a glassy look.
- Skip it if you find text hard to read over busy pages.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Translucent Sidebar**. Or run:

```sh
diatweaks enable translucentSidebar
```

## FAQ

<details>
<summary><strong>Can I change the material?</strong></summary>

Yes. Turn on [Window Material](Window-Material) and pick one there. With Window material off, it uses the same material as the window's background.

</details>
