Hides the "Personalization on for new chats" button at the top right of new tab pages.

## Why use it

If you don't use chat personalization, the button at the top right of the new tab page is clutter. This hides it.
It has no effect while [Hide Toolbar](Hide-Toolbar) is on, because that already hides the toolbar the button sits in.

## Turn it on

Open **Dia → Settings → Patches** and switch on **Hide Personalize Button**. Or run:

```sh
diatweaks enable hidePersonalizeButton
```
