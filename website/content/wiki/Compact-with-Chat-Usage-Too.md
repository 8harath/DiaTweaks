
Compacts the command bar like [Compact Command Bar](Compact-Command-Bar) does, even when your account has chat usage. That hides **Add tabs or files** and dictation, so you can't use them from the command bar while it's on.

## Why use it

If you have chat usage but never use **Add tabs or files** or dictation, this gives you the same one-line bar.
You can't use those buttons from the command bar while it's on, so skip it if you attach tabs or files, or dictate, there.

## Turn it on

Open **Dia → Settings → Patches → Compact Command Bar** and switch on **Compact with Chat Usage Too**. Or run:

```sh
diatweaks enable compactCommandBarWithChat
```

## Needs

[Compact Command Bar](Compact-Command-Bar). Settings greys out this switch until that's on, and `diatweaks enable compactCommandBarWithChat` offers to turn it on too.
