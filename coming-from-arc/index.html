Documentation/Getting started

A familiar place to start.

You don't have to leave every habit behind. DiaTweaks brings familiar interactions to Dia, one switch at a time.

Start with your browser#

Install Dia and use its own import and setup tools for your browsing data. DiaTweaks customizes Dia; it does not transfer your Arc account, Spaces, extensions, or saved tabs. Keep a copy of anything you need from Arc before changing your setup.

Find the things you miss#

In Arc In DiaTweaks What to expect
Peek Peek on Shift-Click Shift-click a link for a preview over your page. Escape closes it; ⌘O keeps it as a tab.
Little Arc Little Dia Open links from other apps in a small window. Enable it, then relaunch Dia.
A quieter toolbar Hide Toolbar Give the page more room. This tweak is experimental; pair it with Show Toolbar on Hover.
A command bar over the page Open New Tabs in Command Bar Open the command bar without leaving the page you're on.
Collapsible pinned tabs Collapse Pinned Tabs Fold pinned tabs under a Pinned line.
A shortcut to pin a tab Pin Tab Shortcut Use ⌘D to pin the current tab.

These are individual tweaks, not a complete recreation of Arc. Read each page for options, dependencies, and limitations.

Make one change at a time#

After installation, open Dia → Settings → Patches. Pick one tweak, read its preview and instructions, and switch it on. Most changes apply immediately; some ask you to relaunch.

If you prefer Terminal, run diatweaks for an interactive menu, or diatweaks list to see which tweaks are enabled. You can use the Settings interface for everyday changes.

Keep a way back#

DiaTweaks keeps an untouched copy of Dia. To return to the original browser, open Settings → Home → Restore…, or run diatweaks restore. Your guide to updates and recovery covers what changes after installation.
